# Modos Simples e Completo

Os dois modos compartilham um único cenário. Valor, frequência, unidade, duração, odd, chance de acerto/margem e taxa de rendimento acompanham a troca de modo. O modo Simples tem três perguntas; os ajustes adicionais ficam no Completo. Os textos e a comparação financeira refletem as hipóteses atuais, inclusive ganho médio, empate, perda e taxas negativas. O risco simples usa a probabilidade teórica; o completo também apresenta frequências simuladas, que podem variar ligeiramente.

Os valores são preservados ao visitar o assistente. Redefinir parâmetros restaura o cenário inicial compartilhado. Nenhuma alteração foi enviada ao GitHub.

Arquivos de implementação: interface_simulador.py, simulator/simple.py, simulator/shared.py e simulator/ui.css. Execute python -m streamlit run app.py na pasta do projeto.
